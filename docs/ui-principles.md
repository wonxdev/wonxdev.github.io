Everything exists to communicate.

Not decorate.

----------------------------------

Hierarchy

Every screen should immediately answer:

Who is this?

What do they do?

Why should I care?

----------------------------------

Whitespace

Whitespace is preferred over borders.

Whitespace is preferred over colors.

Whitespace is preferred over dividers.

----------------------------------

Cards

Cards group information.

Cards never exist only for decoration.

----------------------------------

Motion

Motion should explain.

Never entertain.

----------------------------------

Consistency

One spacing scale.

One radius system.

One typography system.

One shadow system.

----------------------------------

Color

Accent colors communicate interaction.

Not decoration.

----------------------------------

Information Density

Minimal.

Only show what increases understanding.

----------------------------------

Accessibility

Keyboard first.

Semantic HTML.

Visible focus.

Readable contrast.

----------------------------------

Performance

Every animation should justify its existence.

Every JS file should have a reason to exist.
